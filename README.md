# GALADIMA Manager

Logiciel de gestion pour NAS-GUTI-HAZ GALADIMA.

## Fonctionnalités
- Gestion des achats (vendeurs)
- Gestion du stock de téléphones
- Gestion des réparations
- Gestion des ventes
- Génération de factures et reçus PDF

## Technologie
- Python + Flet (interface moderne)
- Base de données SQLite
- Compilation automatique via GitHub Actions
